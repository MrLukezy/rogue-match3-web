# Boss 技能修订方案（详细设计落地版）

> 目标：把当前 10 个 Boss 的技能修订成一套可直接继续实现的规格文档。
>
> 本文重点解决 4 个问题：
>
> 1. 每个技能具体改成什么效果
> 2. 每个技能会对哪些宝石 / 格子产生什么影响
> 3. 每个技能的表现反馈应该长什么样
> 4. 后续把设计落回代码与文案时，应该遵守哪些统一规则

---

## 1. 设计原则

### 1.1 每个 Boss 的主机制

为避免中后期 Boss 技能同质化，先固定每章主机制：

| Boss | 主机制 | 辅机制 | 尽量少用 |
|---|---|---|---|
| 火 `ember_hollows` | 燃烧扩散 | 短锁、区域点燃 | 大量改色 |
| 冰 `frost_spire` | 冻结、覆霜 | 重点目标压制 | 障碍生成 |
| 土 `stone_grove` | 障碍、墙体 | 护甲、坍塌 | 高频改色 |
| 雷 `storm_peaks` | 瞬时位移、短控 | 过载改色 | 长时间封锁 |
| 毒 `venom_bloom` | 感染扩散 | 腐化、束缚、税色 | 高频位移 |
| 水 `tidal_depths` | 潮流位移 | 回合后再流动、少量珊瑚锚点 | 大量锁定 |
| 幻象 `mirror_circus` | 伪装、假连线 | 轻位移、局部封路 | 障碍堆叠 |
| 熔炉 `iron_forge` | 重压封位 | 锻造障碍、短锁 | 大量覆霜 |
| 光暗 `eclipse_sanctum` | 标记、审判 | 封锁、改色 | 纯障碍堆叠 |
| 虚空 `void_throne` | 扭曲、裂界 | 终局混合压制 | 小散件拼盘 |

### 1.2 技能统一结构

每个技能统一拆成 4 层：

1. **施法目标**：命中哪些格子
2. **实际影响**：对宝石 / 障碍 / 规则造成什么变化
3. **玩家感知**：玩家第一眼应该看到什么
4. **应对方式**：玩家应该如何反制

### 1.3 对“宝石影响”的记录口径

为了便于后续接代码，本文统一用以下几类描述：

- **普通宝石影响**：颜色、状态、可交换性、清除成本变化
- **特殊宝石影响**：是否优先命中、是否可被降级、是否只是被上状态
- **障碍影响**：是否生成新障碍、是否扩张成墙、是否会保留
- **棋盘影响**：行列位移、区域错位、后续回合再扰动
- **规则影响**：税色、步数压力、连锁惩罚等

### 1.4 新增轻量设计概念

本轮设计允许新增 4 个“轻量机制概念”。它们不要求你立刻做成复杂底层系统，但文档先统一：

| 概念 | 含义 | 最低实现方式 |
|---|---|---|
| 潮流行 / 潮流列 | 本回合或下回合会再次位移的行列 | 记录一回合后再次 `rotateRow/rotateCol` |
| 伪装宝石 | 视觉上迷惑玩家的宝石 | 先用“优先改掉将成型匹配的宝石”模拟 |
| 圣印 | 光系标记，供后续技能优先作用 | 先复用 `glass`，但单独文案标记为圣印 |
| 裂界区域 | 虚空扭曲重点区域 | 先用“集中施加多种效果到一条线/一区域”替代 |

## 2. 统一表现规范

### 2.1 棋盘表现

每个技能都至少需要：

- **施法前预警**：被命中的行 / 列 / 区域出现 0.25~0.45 秒预警
- **施法命中反馈**：受影响格子有闪光、边框、图标或浮字
- **施法后残留反馈**：若状态可持续，棋盘上必须留下持续可读的标记

### 2.1.1 当前已实装的轻量预警

当前代码中，已经落地的施法前预警包括：

- `foxfire_ring`：中心格 + 环形落点预警
- `thunder_lance`：整列预警
- `dragon_breath`：整行预警
- `abyss_gaze`：局部 3x3 凝视区预警

并且当前已进一步收紧为：

- `foxfire_ring`：预警看到的环形区域，就是实际点燃区域
- `tail_scorch`：预警看到的整行，就是实际灼烧行
- `chain_burst`：预警看到的行列交叉，就是实际位移的行列
- `tail_wave`：预警看到的列，就是实际被尾浪推动的列
- `abyss_tsunami`：预警看到的行列集合，就是实际被海啸错位的行列
- `abyss_gaze`：预警看到的凝视区，就是最终结算区域
- `emperor_decree`：两处帝令危险区先预警，再按同一区域结算
- `star_abyss_end`：两段星渊塌缩先预警，再按同一区域推进结算

实现方式：

- 运行时通过 `state.bossTelegraph` 临时记录命中行 / 列 / 区域 / 中心点
- 渲染层为格子附加 `cell-telegraph-row` / `cell-telegraph-col` / `cell-telegraph-hit` / `cell-telegraph-center`
- 预警持续约 0.32 ~ 0.36 秒后再正式结算技能

这属于第一版轻量可读性增强。当前重点已从“有预警”推进到“预警与命中一致”。后续仍可以继续升级为：

- 元素专属轨迹光效
- 行列箭头与区域边界动画
- 更细分的音效提示

### 2.2 浮字与提示

统一使用三层提示：

1. Boss 施法名
2. 一句话效果总结
3. 若是持续状态，再补一句应对提示

示例：

- `灰烬扩散：扩散 5 处火势；未处理的火焰会继续蔓延`
- `潮池回旋：2 条潮流行将在你行动后再次滑动`

### 2.3 受影响格子的视觉建议

| 效果 | 建议表现 |
|---|---|
| 燃烧 | 暖色小火焰角标 + 轻微流动外辉 |
| 冻结 | 冷白描边 + 冰晶角标 |
| 覆霜 / 圣印 / 护甲 | 半透明壳层 + 图标区分来源 |
| 锁定 | 锁链 / 锁扣角标 |
| 感染 | 毒雾角标 + 回合数字 |
| 过载 | 闪电裂纹角标 |
| 潮流行列 | 行列边缘箭头 + 水纹底条 |
| 伪装 / 幻象 | 镜面闪烁 + 短暂色偏 |
| 裂界区域 | 紫黑裂纹边缘 + 中心脉冲 |

## 3.1 火系 Boss `ember_hollows`

### 元素定位

- 核心感受：**火势会蔓延，越拖越难收拾**
- 玩家体验：优先灭火，否则盘面会由点变面

### 技能修订表

#### 1) `ember_spark` 余烬火花

**修订后效果**

- 随机点燃 2 / 4 枚宝石（普通 / 精英）
- 优先命中：特殊宝石 > 盘面中央 > 普通宝石

**对宝石的影响**

- 普通宝石：获得 `burning`
- 特殊宝石：同样可被点燃，但不会失去 `special`
- 若宝石有 `glass`：先移除 `glass`，再进入 `burning`

**表现效果**

- 命中格先闪橙红小火星，再出现火焰角标
- 浮字：`2 枚宝石被点燃`

**设计意图**

- 作为火系入门技能，建立“燃烧是持续压力”的认知

#### 2) `tail_scorch` 尾焰灼烧

**修订后效果**

- 随机选 1 行
- 该行内点燃 3 / 5 枚宝石
- 边缘格优先，形成“横扫掠过”的感觉

**对宝石的影响**

- 普通 / 特殊宝石都可被点燃
- 已燃烧宝石不会重复计数，但可刷新提示

**表现效果**

- 施法前整行出现红橙扫光预警
- 命中后该行掠过一次火焰拖尾

**设计意图**

- 让玩家感到某条路径被“火线封住”

#### 3) `cinder_spread` 灰烬扩散

**修订前问题**

- 当前只是改色，主题偏雷 / 幻象

**修订后效果**

- 若场上存在 `burning`：
  - 从每个燃烧源周围优先扩散，共新增 4 / 6 个燃烧目标
- 若场上不存在 `burning`：
  - 先随机点燃 3 / 5 枚，再额外扩散 2 枚

**对宝石的影响**

- 普通宝石：新增 `burning`
- 特殊宝石：可以被点燃，迫使玩家优先处理高价值格
- 有 `glass` 的宝石：玻璃被烧碎后转入燃烧

**表现效果**

- 现有燃烧格向周围弹出火星连线
- 新点燃目标有“灰烬落下再复燃”的视觉

**设计意图**

- 明确它是“扩散技”，不是改色技

#### 4) `foxfire_ring` 狐火之环

**修订后效果**

- 选定 1 个中心格
- 优先点燃中心周围一圈 6 / 8 枚宝石
- 中心格或其中 2 / 3 枚关键格获得 `lockedTurns = 1`

**对宝石的影响**

- 环上的普通宝石：`burning`
- 环上的特殊宝石：保留特殊效果，但被点燃
- 中心关键格：短锁定，形成“火圈核心”压力

**表现效果**

- 施法时显示一圈狐火轨迹
- 被环绕的区域有轻微圆环脉冲
- 当前已实装：中心格与周围一圈目标会先短暂高亮预警，再进入点燃与封位

**设计意图**

- 体现“环形包围”，与其他随机点燃技区分开

#### 5) `wildfire_pounce` 野火扑袭

**修订后效果**

- 大范围点燃 8 / 12 枚宝石
- 额外锁定 2 / 4 枚宝石 2 回合
- 锁定优先命中燃烧区域附近的高价值格

**对宝石的影响**

- 普通宝石：`burning`
- 特殊宝石：可能同时处于 `burning` + `locked`
- 形成高优先级灭火区

**表现效果**

- 棋盘中央到四周爆出冲击波
- 画面热浪、震屏略强于普通技能

**设计意图**

- 作为火系终极技，形成“必须立刻收火”的爆发回合

## 3.2 冰系 Boss `frost_spire`

### 元素定位

- 核心感受：**节奏被按住，关键格被冻结**
- 玩家体验：高价值格会被优先点名，盘面会越来越静止

#### 1) `chill_script` 寒霜刻文

**修订后效果**

- 目标优先级改为：
  1. 特殊宝石
  2. 已冻结宝石
  3. 普通未冻结宝石
- 命中 2 / 4 枚
- 未冻结目标：变 `frozen`
- 已冻结目标：加 `glass` 作为“覆霜强化”

**对宝石的影响**

- 普通宝石：冻结后不可交换
- 特殊宝石：冻结但不失去特殊类型
- 已冻结目标：叠加护层，提高解控成本

**表现效果**

- 目标上方出现冰纹刻印
- 已冻结目标再吃到时，额外出现一层白霜壳裂合效果

**设计意图**

- 修正文案与逻辑不一致的问题，强化“刻文点名”感

#### 2) `frost_page` 霜页扩散

**修订后效果**

- 选 1 个中心格
- 中心冻结
- 十字 4 邻域附加覆霜（`glass`）

**对宝石的影响**

- 中心：`frozen`
- 十字周边：`glass`
- 特殊宝石若在中心：优先被冻结

**表现效果**

- 卷轴展开式十字冰痕
- 中心格有更强冰晶爆点

#### 3) `winter_seal` 冬之封印

**修订后效果**

- 随机 6 / 10 枚宝石
- 未覆霜：附加 `glass`
- 已覆霜：升级为 `frozen`

**对宝石的影响**

- 建立“覆霜 -> 冻结”的升级链

**表现效果**

- 命中格先出现雪封印章，再落下冰晶边框

#### 4) `glacier_column` 冰川立柱

**修订后效果**

- 冻结整列
- 相邻两侧列各附加 2 枚覆霜

**对宝石的影响**

- 该列形成强封路
- 相邻侧列作为“次级缓冲层”

**表现效果**

- 一道冰柱从底部升起贯穿整列

#### 5) `absolute_stillness` 绝对静止

**修订后效果**

- 一行 + 一列全部附加 `glass` 和 `frozen`
- 交点追加一次更亮的冻结标识

**对宝石的影响**

- 行列形成“十字静止区”
- 特殊宝石被命中时成为最高优先解控对象

**表现效果**

- 整个十字区域瞬间失去饱和度，再结出冰层

## 3.3 土系 Boss `stone_grove`

### 元素定位

- 核心感受：**路线被堵，安全区被挤压**
- 玩家体验：不是难在状态复杂，而是可走路径越来越少

#### 1) `pebble_drop` 碎石坠落

**修订后效果**

- 生成 2 / 3 个分散障碍
- 优先落在当前无障碍、但接近匹配热点的区域

**对宝石的影响**

- 目标格直接由 gem 变 `obstacle`
- 特殊宝石若被选中，不保留，直接被岩块替换（高压但低频）

**表现效果**

- 顶部掉落碎石尘土，目标格震动后封死

#### 2) `bark_armor` 树皮护甲

**修订后效果**

- 给 4 / 6 枚宝石附加护层（当前仍复用 `glass`）
- 优先命中棋盘边缘或正在成型的连线附近

**对宝石的影响**

- 普通宝石：首次命中只碎护层
- 特殊宝石：保留 special，但需要额外一次清除

**表现效果**

- 宝石外形成树皮纹理壳层，不再只像纯玻璃

#### 3) `burrow_rise` 地穴升起

**修订前问题**

- 和 `pebble_drop` 都像“再加障碍”

**修订后效果**

- 若场上已有障碍：
  - 优先在已有障碍相邻位置再生长 3 / 4 个障碍
- 若场上障碍很少：
  - 在中下盘生成 1 段短墙（连续 2~3 格）

**对宝石的影响**

- 更强调“地形生长”，不是随机掉石头
- 会主动切断下落路径和横向通路

**表现效果**

- 地面裂开，石柱从下向上顶起

#### 4) `cave_in` 洞穴坍塌

**修订后效果**

- 生成 4 / 6 个障碍
- 锁定 2 / 4 枚宝石 1 回合
- 优先让障碍与锁定形成局部危险区

**对宝石的影响**

- 被锁定宝石不可交换
- 周边障碍压缩玩家救援路线

**表现效果**

- 顶部落石，目标区伴随灰尘和短震屏

#### 5) `elder_root_wall` 古根之墙

**修订后效果**

- 生成 6 / 8 个障碍，优先连成片
- 额外给 4 / 6 枚关键宝石附护甲

**对宝石的影响**

- 形成“先破墙再拿关键格”的局面

**表现效果**

- 根须从边缘延展，和岩石一同把区域封住

## 3.4 雷系 Boss `storm_peaks`

### 元素定位

- 核心感受：**瞬时打断，节奏被电流切碎**
- 玩家体验：不是长期压制，而是关键时刻被强行打乱

#### 1) `static_pin` 静电钉锁

**修订前问题**

- 当前只有改色，和名字不符

**修订后效果**

- 锁定 2 / 3 枚宝石 1 回合
- 再额外改色 3 / 5 枚宝石
- 改色优先命中被锁定周边格

**对宝石的影响**

- 普通宝石：短时无法交换
- 特殊宝石：可能被短时锁住，但不失去特殊效果

**表现效果**

- 锁定目标上先闪一道竖向电钉，再出现短锁标识

#### 2) `thunder_lance` 雷枪贯穿

**修订后效果**

- 预警一列
- 该列整体位移 1 格

**对宝石的影响**

- 该列所有 gem / obstacle 一并位移
- 会瞬时打断正在形成的列匹配

**表现效果**

- 施法前一条直线预警，随后雷枪穿透整列
- 当前已实装：整列先短暂高亮预警，再发生列位移

#### 3) `overload_mark` 过载烙印

**修订后效果**

- 改色 8 / 12 枚宝石
- 锁定 2 / 3 枚宝石 1 回合
- 优先命中同色密集区域

**对宝石的影响**

- 打散玩家快要成形的大连线
- 将局部区域转成“暂时不好接”的状态

**表现效果**

- 命中区浮现电路纹理，再发生瞬时颜色跳变

#### 4) `chain_burst` 连锁冲裂

**修订后效果**

- 位移 1 行 + 1 列
- 行列交点附近额外改色 2 / 4 枚

**对宝石的影响**

- 不再只是纯位移，而是形成“连锁冲击中心”

**表现效果**

- 行列先后被电流扫过，交点爆出链式火花

#### 5) `duel_of_storms` 风暴决斗

**修订后效果**

- 连续位移 3 / 4 次列
- 额外改色 10 / 14 枚宝石
- 最后锁定 2 / 3 枚高价值格 1 回合

**对宝石的影响**

- 强调“多段高速扰动”而不是持续封锁

**表现效果**

- 多段落雷 + 连续位移 + 强震屏

## 3.5 毒系 Boss `venom_bloom`

### 元素定位

- 核心感受：**感染会长大，盘面会腐坏**
- 玩家体验：拖延处理的代价越来越高

> 毒系总体已较成熟，本轮只做轻量收束。

#### 1) `toxin_dust` 毒尘散播

**修订后效果**

- 感染 5 / 8 枚宝石 2 回合

**对宝石的影响**

- 普通 / 特殊宝石都可感染
- 不影响立即交换，但会在后续扩散

**表现效果**

## 4. 对每类宝石 / 格子的统一影响说明

## 4.1 普通宝石

普通宝石是所有 Boss 技能的主要命中对象。

统一影响规则：

- 火：点燃后首次消除只灭火
- 冰：冻结后不可交换；覆霜后多一次处理成本
- 土：可能被障碍替换或被护甲覆盖
- 雷：会被位移、改色、短锁
- 毒：会被感染并成为后续扩散源
- 水：会被行列带走，并可能在回合后再次移动
- 幻象：会被优先改成“误导玩家判断”的颜色布局
- 熔炉：会被短锁、被工业封锁区压住
- 光暗：会先被标记，再被封锁或重判
- 虚空：会在局部裂界区里被混合扭曲

## 4.2 特殊宝石

特殊宝石原则上 **不应被大量直接删除其 special**，否则玩家挫败感太强。

建议统一规则：

- 可以被：点燃、冻结、锁定、感染、护层覆盖、位移、改色（若颜色存在）
- 不建议被：高频直接转障碍、直接降级为普通宝石
- 若技能需要高压：优先作用于特殊宝石周边，而不是直接把特殊宝石本体废掉

## 4.3 障碍

建议保持以下分工：

- 土 / 熔炉 / 虚空：主要制造障碍
- 水：只做少量“珊瑚锚点”障碍
- 冰 / 雷 / 幻象：尽量不以障碍为主

## 4.4 行列与区域控制

建议明确：

- 雷：位移更“瞬时、爆裂”
- 水：位移更“持续、流动”
- 幻象：位移更“误导、扭曲”
- 虚空：区域更“撕裂、塌缩”

## 6. 最终结论

本次修订的核心不是单纯“加强 Boss”，而是让 Boss 技能做到：

- **主题更鲜明**
- **效果更可读**
- **玩家更能理解为什么输 / 为什么要优先处理某一区域**
- **后期 Boss 不再只是锁定、玻璃、障碍、改色的换皮组合**

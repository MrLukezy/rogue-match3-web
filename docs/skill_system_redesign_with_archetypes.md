# 宝石技能系统重设计方案（含流派）

## 1. 目标

- 把玩家宝石技能整理成统一系统，围绕核心目标：**让玩家更方便地消除宝石**
- 让玩家一眼能看懂：
  - 我当前属于什么流派
  - 我的技能怎么联动
  - 下一次成长该补什么
- 保留现有项目中"自动触发、强调爽感连锁"的核心体验

## 3. 流派设计

### 3.1 五大主流派

#### 毁灭流（Destruction Build）

- **核心关键词**：直接、范围、爆发
- **适合技能**：
  - 爆破、连锁闪电、十字斩、宝石雨、溅射、粉碎
- **流派特征**：
  - 追求直接大范围消除
  - 适合高压盘面快速清屏

#### 染色流（Color Build）

- **核心关键词**：颜色、同色、转化
- **适合技能**：
  - 色彩同化、染色目标、彩虹桥、色相轮回、邻近模仿、镜像复制
- **流派特征**：
  - 强调颜色聚焦与三消机会创造
  - 适合围绕特定颜色做build

#### 附魔流（Enchant Build）

- **核心关键词**：强化、积累、触发
- **适合技能**：
  - 爆炸强化、横竖强化、连击强化、护盾强化、吸收强化、再生强化
- **流派特征**：
  - 先积累强化宝石，再一次性触发
  - 适合终局爆发收割

#### 触发流（Trigger Build）

- **核心关键词**：连锁、连锁反应、放大
- **适合技能**：
  - 即时引爆、连锁引爆、定时爆破、条件爆破、共鸣引爆、强化优先
- **流派特征**：
  - 追求强化宝石的连锁反应
  - 适合滚雪球式爆发

#### 综合流（Hybrid Build）

- **核心关键词**：混合、多元、适应
- **适合技能**：
  - 根据局势灵活组合
- **流派特征**：
  - 不锁定单一流派
  - 根据实际掉落灵活调整

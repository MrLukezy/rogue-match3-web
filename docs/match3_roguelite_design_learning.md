# 三消 + 肉鸽设计学习文档

## 1. 核心结论

### 1.1 核心循环必须是“短反馈 + 长成长”双层结构
- 短反馈：每一步交换都要有即时收益，包括消除、连锁、特殊宝石生成、局势改善。
- 长成长：每层、每章、每次 run 都要有持续成长，包括构筑、路线、主题变化、永久解锁。
- 对当前项目的启发：不能只靠 7 层短流程撑体验，必须增加章节、主题、事件和跨层策略。

可核对来源类别：
- 头部三消产品的关卡节奏与 retention 设计分析
- Roguelite 代表作（如 Slay the Spire / Hades / Dead Cells）开发者访谈与设计复盘

### 1.2 内容节奏不能只靠数值变难，要靠“新问题”变难
- 优秀三消不是简单加目标分数和减步数，而是持续加入新的棋盘条件、目标组合和对局约束。
- Roguelite 的挑战提升也不是单纯加数值，而是加入新的敌人模式、地图风险和资源选择。
- 对当前项目的启发：需要更多主题化楼层、区域规则、事件分支、Boss 机制差异。

可核对来源类别：
- Match-3 关卡设计文章（障碍物、目标、节奏）
- Roguelite 难度曲线与 enemy escalation 设计文章

### 1.3 奖励系统应服务于构筑分化，而不是只做“数值补给”
- 玩家每层后做的选择，应该影响后续玩法风格。
- 奖励池要有方向性：爆发流、连锁流、保守控制流、掉落流、Boss 压制流等。
- 对当前项目的启发：目前奖励更多是局部强化，后续应增加主题奖励、章节奖励、关键路线事件。

可核对来源类别：
- 卡组构筑类 Roguelite 奖励设计分析
- 移动三消经济与 booster 系统拆解

### 1.4 长时长来自“章节变化”，不是单纯更多关卡
- 关卡数量变多只是表层，真正拉长游玩的是章节主题、规则切换和环境差异。
- 常见有效做法：按 biome / chapter 切章节，每章提供 1-2 个独特规则和 1 个特色 Boss。
- 对当前项目的启发：适合扩成多章节塔层结构，每章有自己的主题修饰、事件池和 Boss 变种。

可核对来源类别：
- 程序生成 / biome 设计方法文章
- Roguelite run structure 设计分析

### 1.5 新功能必须分层揭示，避免一次塞满
- 新主题、新障碍、新目标、新 Boss 机制不能同时堆给玩家。
- 推荐做法：按章节和楼层逐步解锁，用 guide/codex 和事件首次介绍。
- 对当前项目的启发：可以延续现有 Tile Guide，把新主题机制按章节首次出现时解锁说明。

可核对来源类别：
- 新手引导与 feature layering 设计文章
- Roguelite onboard / tutorial 设计复盘

## 2. 可直接复用到本项目的方法

### 2.1 章节化 Run 结构
- 第 1 章：基础资源与教学
- 第 2 章：控制与封锁
- 第 3 章：高压与惩罚
- 第 4 章：混合终局与终章 Boss

### 2.2 三消层面的可扩展点
- 新障碍：孵化蛋、腐蚀地块、符文封印、彩色税区
- 新目标：限定颜色收集、护送宝石、净化污染、击破护盾
- 新特殊宝石：链电、穿透、延时爆裂、净化彩晶

### 2.3 肉鸽层面的可扩展点
- 路线事件分支
- 章节主题差异
- 中局精英战 / 试炼层
- 章节奖励与永久解锁

## 3. 建议用于本项目的优先顺序
1. 扩总楼层与章节主题
2. 增加主题修饰与事件池
3. 增加 Boss 变种与章节规则差异
4. 增加更多奖励方向与 support reward
5. 再扩永久成长与更深 meta

## 4. 保守落地原则
- 优先加“内容层”和“规则层”，少动基础交换手感。
- 新系统尽量复用现有状态结构与 guide/codex。
- 每次只引入 1-2 个新规则簇，避免失控。

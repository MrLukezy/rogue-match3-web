# Boss 技能清晰化设计与实现方案

## 目标

让每个 Boss 技能都满足以下四点：

1. 玩家能一眼看出技能作用到了哪里
2. 玩家能理解技能到底改变了哪些宝石/格子状态
3. 技能影响会持续到足以形成决策压力，而不是一闪而过
4. 技能描述、棋盘表现、实际结算三者一致

---

## 统一实现思路

### 1. 机制层

每个技能必须先落到可计算的棋盘状态上，而不是只写提示文案或播放特效。

推荐统一状态类型：

- `burning`：灼伤，首次清除只熄火，可扩散
- `frosted` / `lockedTurns`：冻结/封锁，不可交换或需额外清除
- `armored`：护甲，需要额外命中
- `poisoned`：污染，可扩散/减收益/触发二次扰动
- `overloaded`：过载，回合后扰动颜色或位置
- `illusion`：伪装，显示与实际不完全一致
- `voidmark` / `rift`：虚空裂口或终局类高压标记

### 2. 结算层

每个状态都必须明确：

- 何时施加
- 何时衰减
- 何时扩散或升级
- 遇到消除时如何处理
- 和玻璃、锁定、障碍、特殊宝石如何交互

### 3. 表现层

每个技能至少有三层反馈：

- 棋盘反馈：受影响格子有明确视觉变化
- 提示反馈：Boss 施法名 + 浮字 + 警告语
- 技能书反馈：描述直接说明效果与应对方式

### 4. 文案层

技能文案不能只写气氛词，必须写后果。

例如：

- 不推荐：狐火包围关键格子
- 推荐：点燃 6 枚宝石并短暂锁定 2 枚；未处理的火焰会在下回合扩散

### 5. 验证层

每个技能都必须通过以下检查：

- 不看代码，玩家能否看懂棋盘状态
- 不看棋盘，只读文案，能否理解规则
- 是否存在持续压力
- 是否存在可操作应对策略

## 火系 Boss 作为标杆的设计结论

### 已建立原则

- 火焰技能不只是一层轻特效，而是明确状态：`burning`
- 灼伤宝石首次清除只熄火，第二次才真正消除
- 若本回合未处理，下一回合向周围随机扩散 1~2 枚
- 视觉应克制但清晰：浅底色 + 小标签 + 轻外框

### 火系技能设计模板

- 小技能：点燃少量宝石，建立认知
- 中技能：点燃 + 行/区域限制
- 大技能：点燃 + 锁定/压力减步 + 扩散威胁

## 十关元素重梳理（当前统一基线）

### 1. 火 `ember_hollows`

- 元素特征：蔓延、高热、逼迫优先处理
- 当前设定：`burning`、短锁、火势扩散
- 目标调整：让火不只是点燃，而是压制玩家的高收益路线
- 已决定规则：**燃烧相关 match 不生成特殊宝石**

### 2. 冰 `frost_spire`

- 元素特征：冻结、停滞、递进封存
- 当前设定：`frozen`、覆霜（复用 `glass`）
- 目标调整：做出“覆霜 -> 冻结”的二段升级
- 已决定规则：**覆霜宝石若未被处理，会在回合后升级为冻结**

### 3. 土 `stone_grove`

- 元素特征：堵路、长墙、压缩空间
- 当前设定：障碍、根墙、护甲
- 目标调整：从随机障碍改为地形生长与通路切断

### 4. 雷 `storm_peaks`

- 元素特征：过载、打断、瞬时短控
- 当前设定：改色、短锁、局部位移
- 目标调整：减少“帮玩家洗盘”的裸位移，改成十字打断与过载核心

### 5. 毒 `venom_bloom`

- 元素特征：感染、扩散、腐坏、越拖越糟
- 当前设定：`poisonedTurns`、束缚、腐化成障碍、税色
- 目标调整：保持滚雪球压力，并打击高收益 match 路线
- 已决定规则：**感染相关 match 不生成特殊宝石**

### 6. 水 `tidal_depths`

- 元素特征：流动、冲刷、余波、站不稳
- 当前设定：潮流行列、回合后再滑动、珊瑚锚点
- 目标调整：位移不应帮玩家洗盘，应伴随残留压力与收益限制
- 已决定规则：**水系位移触发的自动消除不生成特殊宝石**

### 7. 幻象 `mirror_circus`

- 元素特征：误导、伪装、假机会
- 当前设定：假连线、改色、局部封路
- 目标调整：少做大位移，多做关键点伪装与误判

### 8. 熔炉 `iron_forge`

- 元素特征：重压、锻造、工业封位
- 当前设定：障碍、热压锁定、钢焰领域
- 目标调整：和土系进一步区分，强调工业压制而非自然长墙

### 9. 光暗 `eclipse_sanctum`

- 元素特征：标记、审判、双相压制
- 当前设定：圣印、封锁、重判、局部凝视区
- 目标调整：进一步强化“先标记，后审判”的链路

### 10. 虚空 `void_throne`

- 元素特征：扭曲、裂界、规则失真、终局灾变
- 当前设定：局部裂界区、两段危险区、终局塌缩
- 目标调整：减少拼盘式高压，强调局部规则异常

## 第一批已决定落地的规则改动

### A. 特殊宝石生成抑制规则

- 燃烧宝石参与的 4/5 连：**不生成特殊宝石**
- 感染宝石参与的 4/5 连：**不生成特殊宝石**
- 水系位移带来的自动连锁：**不生成特殊宝石**

设计目的：

- 避免 Boss 位移或持续状态反过来帮助玩家滚大收益
- 强化火 / 毒 / 水对“高收益路线”的压制感

### B. 冰系递进规则

- 覆霜（当前仍复用 `glass`）会附加 1 层递进计时
- 若玩家在下回合前未处理，该宝石升级为 `frozen`

设计目的：

- 把冰从“立即冻结”扩展成“逐步封存”
- 增强冰系的读盘压力与优先级管理

### C. 元素行为已接入的底层规则

- 火：燃烧宝石首次消除只灭火，不立即移除
- 冰：冻结宝石不能主动交换；覆霜会递进为冻结
- 雷：部分雷击可把宝石直接击成灰渣，占格并阻碍路径；过载清除会连带打灰周边宝石
- 水：潮流余波带来的自动连锁不会生成特殊宝石；潮湿宝石参与交换时会打滑牵动水流
- 毒：感染宝石参与的高阶 match 不会生成特殊宝石
- 虚空：裂界标记会阻止相关 match 生成特殊宝石

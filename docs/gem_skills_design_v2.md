# 宝石技能系统设计 v2.0

## 概述

宝石技能系统的核心目标：**让玩家更方便地消除宝石**。所有技能都服务于三消，通过直接销毁、颜色改变、宝石强化、宝石触发四种途径，降低消除难度，创造消除机会。

### 品级划分标准

| 品级 | 销毁数量范围 | 概率范围 | 说明 |
|------|-------------|---------|------|
| 普通  | 1-3 颗 | 20%-50%  | 基础技能，辅助单点消除 |
| 稀有  | 4-6 颗 | 50%-70%  | 中级技能，可创造小规模连锁 |
| 传说  | 7-10 颗 | 70%-85%  | 高级技能，可创造大规模消除 |
| 史诗  | 10+ 颗 | 85%-100% | 终极技能，可达成全屏/全局消除 |

---

## 一、直接销毁（Destruction）

直接销毁是最直接的消除方式，通过爆炸、连锁等方式一次性消除多颗宝石。

### 1.1 爆破（Blast）
- **效果**：指定一颗宝石，以其为圆心消除周围宝石
- **概率**：100%
- **销毁数量**：
  - Lv1：2颗（中心+1邻）
  - Lv2：5颗（3x3范围）
  - Lv3：9颗（5x5范围）
  - Lv4：14颗（7x7范围）
  - Lv5：21颗（9x9范围）
- **升级公式**：销毁数 = n×(n+2)，n = 2×等级-1
- **品级**：普通（Lv1-Lv2）→ 稀有（Lv3）→ 传说（Lv4）→ 史诗（Lv5）

### 1.2 连锁闪电（Chain Lightning）
- **效果**：消灭一颗宝石后，电流跳跃至相邻同色宝石继续消灭
- **概率**：100%
- **销毁数量**：
  - Lv1：3颗（1次跳跃）
  - Lv2：6颗（2次跳跃）
  - Lv3：10颗（3次跳跃）
  - Lv4：15颗（4次跳跃）
  - Lv5：21颗（5次跳跃）
- **升级公式**：销毁数 = n×(n+1)/2 + 2，n = 等级+1
- **品级**：普通（Lv1）→ 稀有（Lv2-Lv3）→ 传说（Lv4）→ 史诗（Lv5）

### 1.3 十字斩（Cross Strike）
- **效果**：消除一整行和一整列的宝石
- **概率**：100%
- **销毁数量**：
  - Lv1：9颗（3x3十字）
  - Lv2：15颗（5x5十字）
  - Lv3：25颗（7x7十字）
  - Lv4：35颗（9x9十字）
  - Lv5：49颗（11x11十字）
- **升级公式**：销毁数 = (2×等级+1)² - (2×等级-1)² = 8×等级
- **品级**：稀有（Lv1-Lv2）→ 传说（Lv3-Lv4）→ 史诗（Lv5）

### 1.4 宝石雨（Meteor）
- **效果**：随机掉落特殊宝石，落地时消除落点周围宝石
- **概率**：85%
- **销毁数量**：
  - Lv1：4颗（1颗落地，消除3邻）
  - Lv2：8颗（2颗落地，各消除3邻）
  - Lv3：15颗（3颗落地，各消除4邻）
  - Lv4：24颗（4颗落地，各消除5邻）
  - Lv5：36颗（5颗落地，各消除6邻）
- **升级公式**：销毁数 = 等级 × (等级+3)
- **品级**：普通（Lv1）→ 稀有（Lv2）→ 传说（Lv3-Lv4）→ 史诗（Lv5）

### 1.5 溅射（Splatter）
- **效果**：消除一颗宝石时，30%概率触发额外溅射伤害
- **概率**：30%（可升级）
  - Lv1：30%
  - Lv2：40%
  - Lv3：50%
  - Lv4：65%
  - Lv5：80%
- **销毁数量**（触发时）：
  - Lv1：3颗
  - Lv2：5颗
  - Lv3：7颗
  - Lv4：10颗
  - Lv5：14颗
- **升级公式**：溅射销毁数 = 2×等级+1
- **品级**：普通（Lv1-Lv2）→ 稀有（Lv3）→ 传说（Lv4）→ 史诗（Lv5）

### 1.6 粉碎（Shatter）
- **效果**：对单颗宝石造成巨大伤害，有概率粉碎周围同色宝石
- **概率**：60%（可升级）
  - Lv1：60%
  - Lv2：70%
  - Lv3：80%
  - Lv4：90%
  - Lv5：100%
- **销毁数量**（触发时）：
  - Lv1：4颗
  - Lv2：8颗
  - Lv3：13颗
  - Lv4：19颗
  - Lv5：28颗
- **升级公式**：销毁数 = n×(n+1)/2 + 3，n = 2×等级
- **品级**：稀有（Lv1-Lv2）→ 传说（Lv3-Lv4）→ 史诗（Lv5）

## 二、颜色改变（Color Change）

通过改变宝石颜色，将不易消除的宝石变为容易消除的同色宝石组合。

### 2.1 色彩同化（Color Assimilation）
- **效果**：将3x3范围内宝石变为主目标宝石的颜色
- **概率**：100%
- **三消预估**：
  - Lv1：60%概率形成三消（3颗同色）
  - Lv2：75%概率形成三消（4颗同色）
  - Lv3：85%概率形成三消（5颗同色）
  - Lv4：92%概率形成三消（6颗同色）
  - Lv5：100%概率形成三消（7+颗同色）
- **升级公式**：三消概率 = 50% + 10%×等级
- **品级**：普通（Lv1）→ 稀有（Lv2）→ 传说（Lv3-Lv4）→ 史诗（Lv5）

### 2.2 染色目标（Paint Target）
- **效果**：指定一颗宝石变为指定颜色
- **概率**：100%
- **三消预估**：
  - Lv1：40%概率（需周围配合）
  - Lv2：55%概率
  - Lv3：70%概率
  - Lv4：85%概率
  - Lv5：100%概率（自动匹配最佳颜色）
- **升级公式**：三消概率 = 30% + 10%×(等级+1)
- **品级**：普通（Lv1-Lv2）→ 稀有（Lv3）→ 传说（Lv4）→ 史诗（Lv5）

### 2.3 彩虹桥（Rainbow Bridge）
- **效果**：在两指定宝石之间建立路径，将路径上所有宝石变为主目标颜色
- **概率**：90%
- **三消预估**（路径长度转为同色宝石数）：
  - Lv1：4颗同色
  - Lv2：6颗同色
  - Lv3：8颗同色
  - Lv4：11颗同色
  - Lv5：15颗同色
- **升级公式**：同色数 = 2×等级+2
- **品级**：普通（Lv1）→ 稀有（Lv2-Lv3）→ 传说（Lv4）→ 史诗（Lv5）

### 2.4 色相循环（Color Cycle）
- **效果**：将一片区域宝石按顺时针循环变色
- **概率**：75%
- **三消预估**：
  - Lv1：50%概率形成三消
  - Lv2：65%概率
  - Lv3：80%概率
  - Lv4：90%概率
  - Lv5：100%概率
- **升级公式**：三消概率 = 40% + 12%×等级
- **品级**：普通（Lv1-Lv2）→ 稀有（Lv3）→ 传说（Lv4）→ 史诗（Lv5）

### 2.5 邻近模仿（Neighbor Mimic）
- **效果**：宝石变为上下左右邻居中出现最多的颜色
- **概率**：100%
- **三消预估**：
  - Lv1：45%概率
  - Lv2：60%概率
  - Lv3：75%概率
  - Lv4：88%概率
  - Lv5：100%概率
- **升级公式**：三消概率 = 35% + 13%×等级
- **品级**：普通（Lv1）→ 稀有（Lv2-Lv3）→ 传说（Lv4）→ 史诗（Lv5）

### 2.6 镜像复制（Mirror Copy）
- **效果**：将一个区域的颜色分布镜像复制到另一区域
- **概率**：85%
- **三消预估**：
  - Lv1：55%概率形成三消
  - Lv2：70%概率
  - Lv3：82%概率
  - Lv4：93%概率

- **升级公式**：三消概率 = 45% + 11%×等级
- **品级**：普通（Lv1）→ 稀有（Lv2）→ 传说（Lv3-Lv4）→ 史诗（Lv5）

## 四、宝石触发（Trigger）

触发已强化的宝石，产生连锁反应。

### 4.1 即时引爆（Instant Trigger）
- **效果**：立即触发所有强化宝石的被动效果
- **概率**：100%
- **销毁数量**：
  - Lv1：3颗（触发1颗强化）
  - Lv2：8颗（触发2颗强化）
  - Lv3：15颗（触发3颗强化）
  - Lv4：25颗（触发5颗强化）
  - Lv5：40颗（触发全部强化）
- **升级公式**：销毁数 = 2^(等级+1) - 1 + 等级×2
- **品级**：普通（Lv1-Lv2）→ 稀有（Lv3）→ 传说（Lv4）→ 史诗（Lv5）

### 4.2 连锁引爆（Chain Trigger）
- **效果**：触发一颗强化宝石后，依次连锁触发周围强化宝石

  - Lv1：5颗（连锁3颗）

  - Lv3：18颗（连锁8颗）
  - Lv4：28颗（连锁12颗）

- **升级公式**：销毁数 = n×(n+3)/2，n = 2×等级+1
- **品级**：普通（Lv1）→ 稀有（Lv2-Lv3）→ 传说（Lv4）→ 史诗（Lv5）

### 4.3 定时爆破（Timed Detonate）
- **效果**：为所有强化宝石设置延迟引爆
- **概率**：85%
- **销毁数量**：

- **升级公式**：销毁数 = 等级² × 2 + 等级 + 2
- **品级**：普通（Lv1）→ 稀有（Lv2）→ 传说（Lv3-Lv4）→ 史诗（Lv5）

### 4.4 条件爆破（Conditional Trigger）

- **升级公式**：销毁数 = n×(n+1) - 1，n = 2×等级-1
- **品级**：普通（Lv1-Lv2）→ 稀有（Lv3）→ 传说（Lv4）→ 史诗（Lv5）

### 4.5 共鸣引爆（Resonance Trigger）

# 玩家祝福系统设计

## 概述

玩家祝福是被动增益技能，安装后在对局中自动生效。祝福围绕三大核心机制设计：

- **动量（Momentum）**：玩家连续消除获得的递进增益
- **蓄能（Charge）**：敌人蓄能时玩家的反击机会
- **触发（Trigger）**：提高技能触发概率和效果

### 祝福升级机制

每个祝福5个等级，升级效果呈指数增长。祝福通过累计战斗评分或使用特定技能石解锁。

---

## 一、动量类祝福（Momentum Blessings）

### 1.1 动能累积（Kinetic Accumulation）
- **效果**：每次消除增加动能，动能越高伤害越高
- **机制**：
  - 每次消除获得基础动能 = 1 + (连击数 × 0.5)
  - 动能上限：100点
  - 每10点动能提供 +5% 伤害加成
- **等级效果（动能上限/伤害倍率）**：
  - Lv1：50点上限，+3% 伤害/10点
  - Lv2：75点上限，+5% 伤害/10点
  - Lv3：100点上限，+8% 伤害/10点
  - Lv4：150点上限，+12% 伤害/10点
  - Lv5：200点上限，+20% 伤害/10点
- **升级公式**：伤害加成 = 2 × 1.5^(等级) % /10点

### 1.2 连击狂热（Combo Mania）
- **效果**：连击数达到阈值时，额外触发一次消除
- **触发条件**：
  - Lv1：连击≥3时，20%概率额外消除
  - Lv2：连击≥3时，35%概率额外消除
  - Lv3：连击≥2时，50%概率额外消除
  - Lv4：连击≥2时，70%概率额外消除
  - Lv5：连击≥2时，100%概率额外消除
- **额外消除数量**：
  - Lv1：1颗
  - Lv2：2颗
  - Lv3：3颗
  - Lv4：4颗
  - Lv5：5颗
- **升级公式**：触发概率 = 15% + 15% × 等级，额外消除 = 等级

### 1.3 势如破竹（Momentum Breaker）
- **效果**：动量达到顶峰时，触发一次免费的全屏消除
- **触发条件（动量需达到上限的百分比）**：
  - Lv1：90%时触发，3x3范围
  - Lv2：85%时触发，5x5范围
  - Lv3：80%时触发，7x7范围
  - Lv4：75%时触发，十字范围
  - Lv5：70%时触发，9x9范围
- **冷却**：每局最多触发1次
- **升级公式**：触发阈值 = 95% - 5% × 等级，范围 = 2×等级+1

### 1.4 动能转化（Kinetic Conversion）
- **效果**：将多余动能转化为回复生命
- **机制**：
  - 动量溢出时（超过上限），将溢出量的10%转化为生命
  - 每1点溢出 = 0.5% 生命回复
- **等级效果（转化效率/溢出容量）**：
  - Lv1：10%转化，50点溢出上限
  - Lv2：15%转化，75点溢出上限
  - Lv3：20%转化，100点溢出上限
  - Lv4：30%转化，150点溢出上限
  - Lv5：50%转化，无限溢出
- **升级公式**：转化率 = 5% + 10% × 等级

---

## 二、蓄能类祝福（Charge Blessings）

### 2.1 蓄能感知（Charge Sense）
- **效果**：感知敌人蓄能进度，提前预警并提供反击机会
- **机制**：
  - 敌人蓄能时显示进度条
  - 蓄能满前1回合可打断
  - 打断成功 = 敌人眩晕1回合 + 玩家获得动量
- **等级效果（感知提前量/打断奖励）**：
  - Lv1：感知50%进度，动量+5
  - Lv2：感知35%进度，动量+10
  - Lv3：感知20%进度，动量+15
  - Lv4：感知10%进度，动量+25
  - Lv5：感知5%进度，动量+40
- **升级公式**：感知阈值 = 60% - 10% × 等级，动量 = 5 × 等级

### 2.2 充能反击（Charged Counter）
- **效果**：敌人蓄能满时，自动触发反击
- **触发条件**：
  - 敌人蓄能满且准备释放
  - 玩家有可消除宝石时自动反击
- **效果**：
  - 消除玩家最近的一组宝石
  - 造成敌人蓄能量 × 50% 的伤害
- **等级效果（反击伤害/触发率）**：
  - Lv1：50%伤害，20%触发
  - Lv2：75%伤害，35%触发
  - Lv3：100%伤害，50%触发
  - Lv4：150%伤害，70%触发
  - Lv5：200%伤害，90%触发
- **升级公式**：伤害倍率 = 0.5 × 2^(等级-1)，触发率 = 15% + 15% × 等级

### 2.3 能量吸收（Energy Absorb）
- **效果**：敌人蓄能时，玩家吸收部分能量为自己所用
- **机制**：
  - 敌人每次蓄能，玩家获得等量能量积累
  - 能量可用于增强下一次消除
- **等级效果（吸收比例/能量上限）**：
  - Lv1：吸收5%，上限50
  - Lv2：吸收10%，上限100
  - Lv3：吸收15%，上限150
  - Lv4：吸收25%，上限250
  - Lv5：吸收40%，无上限
- **升级公式**：吸收率 = 3% + 7% × 等级，能量上限 = 50 × 2^(等级-1)

### 2.4 蓄能削弱（Charge Weaken）
- **效果**：降低敌人蓄能速度
- **机制**：
  - 敌人蓄能所需时间延长
  - 蓄能条增长速度降低
- **等级效果（削弱比例）**：
  - Lv1：蓄能速度 -10%
  - Lv2：蓄能速度 -20%
  - Lv3：蓄能速度 -30%
  - Lv4：蓄能速度 -45%
  - Lv5：蓄能速度 -60%
- **升级公式**：削弱率 = 8% × 等级 + 2%

## 三、触发类祝福（Trigger Blessings）

### 3.1 幸运光环（Lucky Aura）
- **效果**：提高所有技能的触发概率
- **机制**：
  - 基础技能触发概率 +X%
  - 享受幸运加成的技能不包括100%触发的技能
- **等级效果（触发加成）**：
  - Lv1：+5% 触发率
  - Lv2：+10% 触发率
  - Lv3：+15% 触发率
  - Lv4：+22% 触发率
  - Lv5：+30% 触发率
- **升级公式**：触发加成 = 3% × 等级 + 2%

### 3.2 技能冷却缩减（Cooldown Reduction）
- **效果**：减少技能冷却时间
- **机制**：
  - 所有技能冷却时间减少X%
  - 被动技能刷新加快
- **等级效果（冷却缩减）**：
  - Lv1：-10% 冷却
  - Lv2：-18% 冷却
  - Lv3：-28% 冷却
  - Lv4：-40% 冷却
  - Lv5：-55% 冷却
- **升级公式**：冷却缩减 = 8% × 等级 + 2%

### 3.3 连锁觉醒（Chain Awakening）
- **效果**：连锁消除时，概率触发技能自动释放
- **机制**：
  - 3连消：5%概率触发
  - 4连消：10%概率触发
  - 5连消：20%概率触发
  - 每增加1连消，概率 +15%
- **等级效果（触发倍率/连锁加成）**：
  - Lv1：1.0倍触发率，+10%/连消
  - Lv2：1.2倍触发率，+12%/连消
  - Lv3：1.5倍触发率，+15%/连消
  - Lv4：2.0倍触发率，+18%/连消
  - Lv5：2.5倍触发率，+25%/连消
- **升级公式**：触发倍率 = 0.8 + 0.4 × 等级，连消加成 = 8% + 3% × 等级

### 3.4 暴击祝福（Critical Blessing）
- **效果**：技能触发时，概率造成双倍效果
- **机制**：
  - 暴击时伤害/范围翻倍
  - 不与其他翻倍效果叠加
- **等级效果（暴击概率/暴击效果）**：
  - Lv1：10%暴击率，1.5倍效果
  - Lv2：15%暴击率，1.8倍效果
  - Lv3：22%暴击率，2.0倍效果
  - Lv4：30%暴击率，2.5倍效果
  - Lv5：40%暴击率，3.0倍效果
- **升级公式**：暴击率 = 8% + 6% × 等级，暴击效果 = 1.3 + 0.4 × 等级

### 3.5 技能连发（Skill Barrage）
- **效果**：技能触发后，概率继续触发其他技能
- **机制**：
  - 每次技能触发后，X%概率触发另一个随机技能
  - 连发技能不消耗额外行动
- **等级效果（连发概率/连发次数上限）**：
  - Lv1：10%概率，连发1次
  - Lv2：15%概率，连发2次
  - Lv3：22%概率，连发3次
  - Lv4：30%概率，连发4次
  - Lv5：40%概率，无限连发
- **升级公式**：连发概率 = 5% + 7% × 等级

## 四、综合类祝福（Hybrid Blessings）

### 4.1 绝境逢生（Desperate Survival）
- **效果**：生命值低时获得强力增益
- **触发条件（生命值低于）**：
  - Lv1：20%生命，+15%伤害
  - Lv2：25%生命，+25%伤害，+10%技能触发
  - Lv3：30%生命，+40%伤害，+18%技能触发
  - Lv4：35%生命，+60%伤害，+28%技能触发
  - Lv5：40%生命，+100%伤害，+40%技能触发
- **升级公式**：伤害加成 = 10% × 2^(等级-1)，触发加成 = 8% × 等级

### 4.2 战场统治（Battlefield Control）
- **效果**：控制棋盘格局，创造有利消除条件
- **机制**：
  - 每回合开始时，10%概率重排棋盘
  - 重排倾向于创造更多三消机会
- **等级效果（重排概率/优化程度）**：
  - Lv1：5%重排，优化10%三消机会
  - Lv2：8%重排，优化18%三消机会
  - Lv3：12%重排，优化28%三消机会
  - Lv4：18%重排，优化40%三消机会
  - Lv5：25%重排，优化60%三消机会
- **升级公式**：重排概率 = 3% + 4% × 等级，优化 = 8% + 10% × 等级

### 4.3 完美主义（Perfectionist）
- **效果**：强迫症式的精准消除，奖励完美操作
- **机制**：
  - 消除恰好3颗：正常效果
  - 消除4颗：1.2倍效果
  - 消除5颗：1.5倍效果
  - 消除6颗及以上：2.0倍效果
- **等级效果（完美加成/4消奖励）**：
  - Lv1：4消1.2倍，5消1.5倍
  - Lv2：4消1.3倍，5消1.7倍
  - Lv3：4消1.4倍，5消2.0倍
  - Lv4：4消1.5倍，5消2.3倍
  - Lv5：4消1.6倍，5消2.5倍
- **升级公式**：4消加成 = 1.15 + 0.1 × 等级，5消加成 = 1.4 + 0.2 × 等级

### 4.4 资源回收（Resource Recovery）
- **效果**：未触发的技能概率返还冷却
- **机制**：
  - 技能未触发时，X%概率返还50%冷却
  - 只有消耗类技能触发返还
- **等级效果（返还概率）**：
  - Lv1：5%返还
  - Lv2：10%返还
  - Lv3：15%返还
  - Lv4：22%返还
  - Lv5：30%返还
- **升级公式**：返还概率 = 3% + 5% × 等级

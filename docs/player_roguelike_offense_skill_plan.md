# 玩家宝石技能方案

## 目标

- 所有玩家技能围绕核心目标：**让玩家更方便地消除宝石**
- 技能通过四种途径帮助玩家：
  - 直接销毁
  - 颜色改变
  - 宝石强化
  - 宝石触发

## 技能栏规则

- 最多携带 5 个技能
- 开局默认不带技能；逐步通过楼层奖励获得
- 技能均为被动触发
- 技能来源：楼层奖励、事件奖励、连锁掉落、章节奖励

## 技能池

### 直接销毁类（6个）

| 名称 | 稀有度 | 效果 |
|---|---|---|
| 爆破 | 普通 | 以目标为圆心消除周围宝石 |
| 连锁闪电 | 普通 | 跳跃消灭相邻同色宝石 |
| 十字斩 | 稀有 | 消除一整行和一整列 |
| 宝石雨 | 普通 | 随机掉落，落地时消除 |
| 溅射 | 普通 | 概率触发额外溅射伤害 |
| 粉碎 | 稀有 | 概率粉碎周围同色宝石 |

### 颜色改变类（6个）

| 名称 | 稀有度 | 效果 |
|---|---|---|
| 色彩同化 | 稀有 | 将周围宝石变为主目标颜色 |
| 染色目标 | 普通 | 指定宝石变为指定颜色 |
| 彩虹桥 | 稀有 | 路径上宝石变为主目标颜色 |
| 色相轮回 | 史诗 | 区域宝石循环变色 |
| 邻近模仿 | 普通 | 变为最常见邻居颜色 |
| 镜像复制 | 史诗 | 复制区域颜色到另一区域 |

### 宝石强化类（6个）

| 名称 | 稀有度 | 效果 |
|---|---|---|
| 爆炸强化 | 普通 | 添加爆炸属性 |
| 横竖强化 | 稀有 | 添加横竖属性 |
| 连击强化 | 稀有 | 添加连击属性 |
| 护盾强化 | 史诗 | 免疫一次消除并反击 |
| 吸收强化 | 史诗 | 消除时偷取对方增益 |
| 再生强化 | 稀有 | 每回合额外消除 |

### 宝石触发类（6个）

| 名称 | 稀有度 | 效果 |
|---|---|---|
| 即时引爆 | 史诗 | 立即触发所有强化宝石 |
| 连锁引爆 | 史诗 | 连锁触发强化宝石 |
| 定时爆破 | 稀有 | 延迟引爆 |
| 条件爆破 | 稀有 | 条件触发 |
| 共鸣引爆 | 传说 | 同色强化宝石共鸣触发 |
| 强化优先 | 史诗 | 优先触发高等级强化 |

## 流派示例

- 毁灭流：爆破 + 连锁闪电 + 粉碎 + 十字斩 + 宝石雨
- 染色流：色彩同化 + 彩虹桥 + 色相轮回 + 邻近模仿 + 镜像复制
- 强化流：爆炸强化 + 横竖强化 + 连击强化 + 即时引爆 + 共鸣引爆

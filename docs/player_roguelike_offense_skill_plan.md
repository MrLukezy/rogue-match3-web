# 玩家肉鸽进攻技能方案

## 目标

- 玩家端不再使用主动点击道具。
- 所有成长统一改为被动进攻技能。
- 技能主要职责是：补清除、扩爆炸、拉连锁、做斩杀。

## 技能栏规则

- 最多携带 5 个技能。
- 技能栏只展示：图标、名称、等级、稀有度。
- 技能均为被动，不需要额外点击释放。
- 技能来源：楼层奖励、事件奖励、连锁掉落、章节奖励。
- 同一轮中，技能与章节祝福都可以跨章节继承，不会在进入下一章节时清空。
- 若玩家直接从后续章节开始，则按章节序号补发若干轮起始技能选择，模拟前面章节的成长积累。

## 技能池

### 普通

1. 回响溅射
   - 每次消除后，对锚点周围追加若干次相邻清除。
   - 适合稳定补刀与拉长基础连锁。

2. 裂阵直击
   - 达成 4 连及以上时，沿锚点打出整行追击。
   - 高等级可变成双行或十字。

3. 追击尾流
   - 每次消除后追加随机追击清除。
   - 适合帮助盘面继续下落和自动连锁。

### 稀有

4. 十字核爆
   - 4 连或连锁时引爆锚点周围区域。
   - 高等级扩大范围，并补十字清线。

5. 同调收割
   - 根据本次主色，额外清除若干同色宝石。
   - 适合颜色爆发流。

### 史诗

6. 九宫脉冲
   - 大消除时触发 3x3 爆炸。
   - 高等级可对多个锚点同时爆炸。

7. 棱镜溢流
   - 连锁时按本次出现的颜色做额外扩散清除。
   - 颜色越杂，收益越高。

8. 连锁过载
   - 特殊连锁会被进一步放大成区域打击。
   - 适合特殊宝石和高连锁构筑。

### 传说

9. 处决矩阵
   - 敌方血量进入斩杀线后，每次消除都会追加处决清除。
   - 负责终局滚雪球和收尾爆发。

## 流派示例

- 溅射流：回响溅射 + 追击尾流 + 十字核爆
- 连锁流：裂阵直击 + 棱镜溢流 + 连锁过载
- 爆炸流：十字核爆 + 九宫脉冲 + 连锁过载
- 斩杀流：同调收割 + 九宫脉冲 + 处决矩阵

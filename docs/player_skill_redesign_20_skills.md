# 玩家宝石技能系统设计（24技能/5级指数成长）

> 目标：重做当前玩家宝石技能体系，使其服务于核心目标——**让玩家更方便地消除宝石**。

---

## 1. 核心规则

### 1.1 技能分类

- **直接销毁（Destruction）**：通过爆炸、连锁等方式一次性消除多颗宝石
- **颜色改变（Color Change）**：将不易消除的宝石变为容易消除的同色组合
- **宝石强化（Enhancement）**：为宝石添加特殊属性，使其在消除时产生更强效果
- **宝石触发（Trigger）**：触发已强化的宝石，产生连锁反应

### 1.2 统一触发规则

| 规则项 | 方案 |
|---|---|
| 技能类型 | 宝石技能 |
| 是否需要条件 | 否（部分技能有概率触发） |
| 触发时机 | 玩家操作后根据技能类型触发 |
| 最高等级 | 5级 |
| 成长方式 | 指数级成长 |

### 1.3 设计原则

- 技能必须直接帮助：**补清除、扩散、制造连锁、扩大范围、控盘、斩杀**
- 不做"纯数值 +X% 伤害"式成长，优先做**目标数、范围、链数、重复次数、扩散层级**的增长
- 每升一级都比前一级增加更多，不是线性加1

|---|---|---|---|---|
| `blast` | 爆破 | 普通 | 以目标为圆心消除周围宝石 | 2→5→9→14→21颗 |
| `chainLightning` | 连锁闪电 | 普通 | 跳跃消灭相邻同色宝石 | 3→6→10→15→21颗 |
| `crossStrike` | 十字斩 | 稀有 | 消除一整行和一整列 | 9→15→25→35→49颗 |

| `splatter` | 溅射 | 普通 | 概率触发额外溅射伤害 | 3→5→7→10→14颗（30%→80%） |
| `shatter` | 粉碎 | 稀有 | 概率粉碎周围同色宝石 | 4→8→13→19→28颗（60%→100%） |

## 4. 品级划分标准

| 品级 | 销毁数量范围 | 概率范围 | 说明 |
|------|-------------|---------|------|
| 普通  | 1-3 颗 | 20%-50%  | 基础技能，辅助单点消除 |
| 稀有  | 4-6 颗 | 50%-70%  | 中级技能，可创造小规模连锁 |

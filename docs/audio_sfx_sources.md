# 音效资源整理

## 当前接入来源

### 1. Kenney - Interface Sounds
- 来源：https://www.kenney.nl/assets/interface-sounds
- 许可证：CC0
- 用途：UI、切换、净化、提示、连锁辅助音

### 2. Kenney - Impact Sounds
- 来源：https://www.kenney.nl/assets/impact-sounds
- 许可证：CC0
- 用途：命中、重击、钟鸣、金属冲击、敌方施法冲击

### 3. OpenGameArt - RPG Sound Pack
- 来源：https://opengameart.org/content/rpg-sound-pack
- 许可证：CC0
- 用途：挥砍、法术、怪物攻击、魔法技能、Boss / 小兵攻击音

## 当前映射方向

### 普通技能
- 回响溅射：玻璃轻击 / 碎裂感
- 裂阵直击：挥砍 / 扫线
- 十字核爆：法术爆裂 + 横扫
- 同调收割：选择 / 共鸣提示
- 追击尾流：切换 / 旋流
- 九宫脉冲：重钟鸣 / 冲击波
- 棱镜溢流：魔法法术 / 彩虹扩散
- 连锁过载：故障 / 高压电流
- 处决矩阵：重拳冲击 / 终结重击

### 条件技能
- 连锁矩阵：金属冲击 + 扫线
- 热潮引擎：魔法法术 + 冲击
- 净化印记：玻璃 / 净化提示
- Boss 分流：警报 / 抽能压制

### 敌方攻击
- 小怪攻击：较轻的金属 / 投射音
- Boss 小技能：中等金属冲击 / 施法音
- Boss 大技能：重型钟鸣 / 重压施法音

## 当前入库策略

- 当前优先采用 **可免费商用的 CC0 资源**，避免额外署名与商业限制风险。
- 仓库内只保留实际接入的精选音效文件，统一放在 `assets/audio/skill_sfx/`。
- 原始下载压缩包与整包解压目录已清理，避免仓库体积膨胀。

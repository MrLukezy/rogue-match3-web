## Shared art direction

- polished fantasy mobile game UI icon / skill VFX concept
- centered composition, single clear subject, clean silhouette, high contrast
- readable at small size, crisp edge lighting, magical energy accents
- no text, no watermark, no UI frame, no hands, no busy background
- for icons: square 1:1 composition, premium match-3 rogue-lite style
- for effect source images: single isolated magical effect, centered, black or very dark background acceptable for later extraction/reference
